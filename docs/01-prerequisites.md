# 1. Prerequisites

You need these installed on your computer before you can work on the project.

| Tool | Version we use | Why you need it | Check it with |
|------|----------------|-----------------|---------------|
| Python | 3.12+ | The programming language the project is written in | `python --version` |
| pip | comes with Python | Installs Python libraries | `python -m pip --version` |
| Git | any recent | Saves the history of your code and uploads it to GitHub | `git --version` |
| A code editor | — | VS Code or PyCharm recommended | — |

## Installing Python on Windows

1. Download it from <https://www.python.org/downloads/>.
2. In the installer, **tick "Add python.exe to PATH"**. Without this, the `python` command
   won't work in the terminal.
3. Open a new terminal and run `python --version`. You should see `Python 3.12.x` or newer.
